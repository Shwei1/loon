## Виконання скрипту на даних файлах

``` shell
./check_format.sh dummy
```

```
==== CLANG-FORMAT VERSION 11 ====
Some files are formatted incorrectly
=================================

==== CLANG-FORMAT VERSION 22.1.8 ====
Some files are formatted incorrectly
=================================
```

Файл `.clang-format` з репозиторія пише, що найстаріша підтримувана версія форматера - 11. Остання встановлена в мене - 22.

# Порівняння форматування версіями 11 і 22

``` shell
./make_format_11.sh dummy
```
``` shell
./make_format_latest.sh dummy
```

Якщо переглянути різницю між відповідними комітами, то можна побачити, що форматер зачепив тільки файли `.c`, а заголовні файли - ні.

Це виключно різниця в індентації для тернарного оператора `:?`, у новішій версії відступ перенесених операндів зробили меншим.

[Повний diff](./diffs/format11_vs_format22.patch)

## Порівняння стилю Chromium між версіями 11 і 22

Різниця доволі велика. Багато де з'явилася більш точна специфікація для вирівнювання елементів, тобто не просто булеве значення, а більше повноцінна таблиця. З'явилися цілком нові категорії вирівнювання (Align-...), (Break-...), (Indent-...). Деякі параметри переіменували. Загалом контроль над форматуванням став набагато більш детальним.
