
#### Використані команди

1. `git init`
2. Створив репозиторій на GitHub і додав туди txt файл з браузера
3. `git remote add origin git@github.com:Shwei1/loon.git`
4. `git add README.md`
5. `git commit -m "Add README.md"`
6. `git add .gitignore`
7. `git commit -m "Add .gitignore"`
8. `git config pull.rebase true`
9. `git pull origin main`
10. `git push --set-upstream origin main`
